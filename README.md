# FinTrack – Personal Expense & Budget Management System

## About the Project

FinTrack is a Python-based desktop application designed to help users manage their personal finances. It allows users to record income and expenses, manage monthly budgets, monitor spending habits and analyze financial activities through graphical visualizations.

## Features

- Dashboard displaying total income, expenses and balance.
- Add and delete income and expense transactions.
- Manage monthly budgets.
- Monitor budget utilization.
- Financial analytics and expense categorization.
- Pie charts and monthly income-versus-expense graphs.
- Persistent data storage using JSON files.

## Technologies Used

- Python
- Tkinter
- NumPy
- Pandas
- Matplotlib
- JSON

## Installation

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `python main.py`

## Project Structure

- `main.py` – Main application and GUI.
- `modules/` – Core application functionality.
- `data/` – Local JSON data storage.
- `assets/` – Application resources.

## Data Storage

FinTrack uses JSON files for local data persistence. No database server is required.

## Project Purpose

This project was developed as a Python mini project to demonstrate object-oriented programming, data structures, file handling, numerical computation, data analysis and GUI development.
